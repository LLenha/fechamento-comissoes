Fechamento de Comissões

Versão de demonstração. Este projeto foi desenvolvido para uma empresa do varejo e está em uso com dados reais. Para preservar informações confidenciais, nesta versão os nomes de lojas e pessoas, os valores e as regras de comissão foram substituídos por dados fictícios, mantendo a mesma lógica de cálculo.

Escolha a loja, preencha os campos cinzas e confira o resultado. Quando as 6 lojas estiverem prontas, abra Fechamento para ver tudo junto e baixar a planilha. Os dados ficam salvos neste computador, no navegador em que o arquivo foi aberto.
